長井龍雪ながい たつゆき

脚本の岡田麿里とのタッグ作品を中心に、青春の痛みを真正面から描く監督です。感情の爆発シーンの演出に定評があります。管理人が「この監督の作品なら観る」と決めている監督です。

1
あの日見た花の名前を僕達はまだ知らない。

監督作です。幼馴染グループの再生を描いた作品で、長井龍雪監督の名を一気に広めた出世作です。

とらドラ!

dアニメ Amazon 🌐 公式
3
空の青さを知る人よ
2019年 / 青春・ドラマ / P.A.WORKS
監督作です。姉妹と昔の恋人を巡る大人の青春群像劇です。岡田麿里脚本との相性の良さが際立つ一作です。
dアニメ Amazon 🌐 公式

新海誠

CoMix Wave Filmsに所属しています。緻密で美しい映像美と、繊細な心理描写を武器にする監督です。個人制作出身という異色の経歴を持ちながら、『君の名は。』で興行収入250億円を超える国民的大ヒットを記録し、日本アニメ映画の新たな時代を切り開きました。

幾原邦彦

高松信司たかまつ しんじ

1983年に日本サンライズ（現・サンライズ）入社、ガンダムシリーズなどで演出を経験した後、『銀魂』の初期シリーズで監督を務め、注目を集めました。『男子高校生の日常』『坂本ですが？』などのコメディ作品でも監督を務め、テンポの良い脚本・演出に定評があります。『ぐらんぶる』シリーズでは監督・脚本・音響監督まで一貫して担当し、原作の空気感をそのままスクリーンに落とし込む手腕を発揮しています。

1
銀魂
2006年〜 / ギャグ・SF時代劇 / スタジオぎゃろっぷ
初期シリーズ（2006年〜）の監督作です。坂田銀時たちが騒動を巻き起こす長寿シリーズで、コメディとシリアスの緩急を生かした作風で知られる、代表作のひとつです。
dアニメ Amazon 🌐 公式
2
坂本ですが？
2016年 / ギャグ・学園コメディ / Studio Deen
監督・全話脚本・音響監督を兼任しています。何をしても様になりすぎる高校生・坂本を巡るシュールな笑いを、間の取り方まで含めて緻密に演出した一作です。
dアニメ Amazon 🌐 公式
3
ぐらんぶる
2018年〜（Season3は2026年） / ギャグ・青春 / ZERO-G
監督・脚本・音響監督を兼務しています。Season3ではパラオを舞台に、豪華声優陣のアドリブ感あふれる掛け合いと、笑いの合間にふと挟み込む感情描写のギャップを丁寧に描いています。
dアニメ 🌐 公式
