名探偵コナン初心者ガイド
【親から子へ、今から見せるならこの順番で】

📅 2026年9月更新✍️ ANIMEDB管理人⏱ 読了目安：約10分
🕵️ 原作・アニメ8割、劇場版は全29作品視聴済み
管理人自身が子供の頃から追いかけてきたシリーズです。自分の子供世代に「そろそろ見せてみようかな」というタイミングが来たので、これから初めて名探偵コナンに触れる小学生高学年くらいのお子さんと、それを見せる親世代の両方に向けて、無理なく入っていける道筋をまとめました。

1. どこから見始めるべきか

まず知っておいてほしいのが、名探偵コナンは1996年にアニメ放送が始まり、2026年1月時点でテレビアニメだけで1188話、劇場版は今年公開の最新作を含めて通算29作品というとんでもないボリュームのシリーズだということです。全部を1話から見ようとすると、単純計算でも500時間を超えます。

1188話

だからこそ、子供に「1話から全部見せなきゃ」と気負う必要はありません。おすすめは、まず次で紹介する序盤の数話で基本設定（工藤新一がなぜ江戸川コナンになったのか）だけ押さえてから、単発で楽しめる劇場版に寄り道する、という入り方です。本編は気に入った時に少しずつ追いつけばよく、むしろ「腰を据えて全部見る」より「気になったところから摘み食いする」方が、長寿シリーズとの付き合い方としては続きやすいと感じています。

2. 序盤の神回ピックアップ

本編を1話から見る場合、最低限ここまでは押さえておきたいという回を選びました。

1
第1話「ジェットコースター殺人事件」
1996年1月8日放送
シリーズ全ての出発点。高校生探偵・工藤新一が、謎の組織に薬を飲まされて体を小学生に縮められてしまい、正体を隠すため「江戸川コナン」を名乗る、という基本設定がここで語られます。ここを見ずに他の回から入ると、コナンの正体を知っている前提の話がほとんどなので混乱してしまいます。
ここだけは外せない：コナンがなぜ小学生の姿なのか、という一番の謎がここで明かされます。
2
第2話「社長令嬢誘拐事件」
1996年1月15日放送
コナンが毛利小五郎・蘭の毛利探偵事務所に居候することになった経緯が描かれる回。「江戸川コナン」という名前がどう決まったかもここで分かります。以降の話の舞台となる毛利探偵事務所が登場する、生活面での基本設定回です。
ここが分かる：コナンがなぜ毛利探偵事務所で暮らしているのか。
3
第3話「アイドル密室殺人事件」
1996年1月22日放送
コナンが阿笠博士が発明した。蝶ネクタイ型変声機で小五郎の声を借りて推理を披露する「眠りの小五郎」の基本パターンがここで確立します。以降の話の「お約束」を理解するための回です。
ここが分かる：コナンが事件を解決する時の、お決まりの推理スタイル。
4
第5話「新幹線大爆破事件」
1996年2月5日放送
コナンを小さくした黒ずくめの組織のメンバー、ジンとウォッカが物語として関わる回。2人の初登場は第1話ですが、この回であらためて動き出すことで、シリーズ全体を貫く「黒の組織」というもう一つの大きな軸が、少しずつ存在感を増していきます。
ここが分かる：コナンを追う黒幕、黒の組織の存在。
5
第128話「黒の組織10億円強奪事件」
1998年12月14日放送
後にコナンの仲間になる灰原哀（正体は宮野志保）の姉・宮野明美が、最初で最後に登場する回。妹を組織から抜けさせようとする姉の想いが描かれる、シリーズ屈指の切ない回で、灰原哀というキャラクターの背景を理解するうえで欠かせません。
ここが分かる：のちに仲間になる灰原哀が、なぜ組織から逃げてきたのか。

3. 映画から入るならこの5本

劇場版は全29作品を観ていますが、その中でも「これから見る人」にまず薦めたい5本です。基本的に1本ずつ独立した話なので、本編を追いつく前に映画から入っても問題なく楽しめます。公開年順に並べているので、シリーズの雰囲気の広がりも合わせて感じてもらえると思います。

1
名探偵コナン 時計じかけの摩天楼
1997年4月19日公開 / 劇場版第1作 / 監督：こだま兼嗣
記念すべき劇場版第1作。連続爆破事件を仕掛ける犯人を追う中で、蘭と新一の絆が事件解決の鍵になります。登場人物がまだ少なく、後の作品に比べてシンプルな構成なので、映画から入る一本目として一番おすすめです。
おすすめの理由：シリーズの原点であり、余計な前提知識がいらない一本。
Hulu
2
名探偵コナン ベイカー街の亡霊
2002年4月20日公開 / 劇場版第6作 / 監督：こだま兼嗣
新型VRゲーム「コクーン」の発表会に招待されたコナンが、暴走したAI「ノアズ・アーク」に支配されたシャーロック・ホームズの世界を舞台に、50人の子供たちの命を救うため奮闘する一作。推理アニメとSF・ゲーム世界が融合した、シリーズでも屈指のスケール感が魅力です。
おすすめの理由：VR世界という子供にも分かりやすい舞台設定で、王道の名作として名高い一本。
Hulu
3
名探偵コナン 探偵たちの鎮魂歌
2006年4月15日公開 / 劇場版第10作（10周年記念） / 監督：山本泰一郎
横浜のテーマパークを訪れた小五郎とコナンが、「12時間以内に事件を解決しなければ全員を爆死させる」という謎の脅迫を受ける一作。シリーズ10周年記念として、怪盗キッドを含むレギュラーキャラがほぼ全員登場するオールスター編で、コナンの世界の広さを一気に味わえます。
おすすめの理由：怪盗キッドをはじめ主要キャラが勢揃いする、お祭り感のある一本。
Hulu
4
名探偵コナン から紅の恋歌
2017年4月15日公開 / 劇場版第21作 / 監督：静野孔文
大阪・京都を舞台に、百人一首の高校生大会を巡って事件が連続する一作。服部平次のライバル・大岡紅葉が登場し、平次と和葉の関係にも大きく踏み込みます。公開時の興行収入68.8億円は、当時のシリーズ最高記録。それだけ幅広い層に評価された一本です。
おすすめの理由：百人一首という日本文化を絡めたミステリーと、平次たちの関西コンビの魅力が詰まった一本。
Hulu
5
名探偵コナン ハロウィンの花嫁
2022年4月15日公開 / 劇場版第25作 / 監督：満仲勧
高木刑事と佐藤刑事の結婚式に招待されたコナンたちが、謎の殺し屋プラーミャによる連続爆破テロに巻き込まれる一作。公開時の興行収入97.8億円は、当時のシリーズ最高記録（その後の作品でさらに更新されています）。派手なアクションと本格ミステリーのバランスが良く、近年の作品から入りたい人にまず薦めたい一本です。
おすすめの理由：高水準の興行成績が示す通り、近年のコナン映画のクオリティの高さが一番分かりやすく詰まっている。
Hulu

4. アニオリとの付き合い方

1188話もある本編には、原作にはないアニメオリジナル回（通称「アニオリ」）もかなりの数含まれています。原作準拠の回だけに絞って追いかけると、視聴時間はおおよそ6割程度まで圧縮できると言われています。子供と一緒に見る場合、最初から全部を律儀に追う必要はなく、「アニオリは息抜き回」くらいに割り切って、テンポが気になってきたら原作準拠の回を優先して見進める、というくらいの気軽さがちょうどいいと感じています。

5. 原作で追う場合のペース感

アニメより先に話が進んでいる原作漫画を電子書籍でまとめ買いして追う、という入り方もおすすめです。1冊がコンパクトなので、寝る前に1〜2話ずつというペースでも子供が自分のペースで読み進めやすく、アニメで基本設定を掴んだあとに原作でどんどん先を追いかける、という流れが作りやすいシリーズだと思います。

6. 次のステップ

序盤の神回と映画5本で基本的な世界観に慣れてきたら、次は黒の組織を巡る本格的な展開へ進むのがおすすめです。ここから先は緊張感のある話が増えてくるので、子供の成長に合わせて少しずつ踏み込んでいくのがちょうどいいペースだと思います。管理人自身、子供の頃に見始めて今も追いかけているシリーズです。今度は自分の子供世代に、同じように少しずつ手渡していけたらと思っています。
