1

天空のエスカフローネ

1996年春 / サンライズ / ファンタジー・ロボット
女子高生のひとみが異世界「ガイア」に迷い込み、戦乱に巻き込まれていく冒険ファンタジーです。ロボットアニメに少女漫画の要素を組み合わせた作品として企画されました。

📌 作品データ1996年4月から9月までテレビ東京系で放送された全26話の作品です。制作はサンライズで、監督は赤根和樹さん、キャラクターデザインは結城信輝さんです。2000年には、設定を一新した劇場版も公開されました。

こんな人に：古典的な冒険ファンタジーが好きな人！

2

serial experiments lain

1998年夏 / トライアングルスタッフ / SFホラー
ネットワークが日常に入り込んだ世界で、内気な中学生の少女・玲音が、現実とネットの境目があいまいになる出来事に巻き込まれていく物語です。説明を絞った作りなので、見る人が自分で解釈しながら楽しむタイプの作品です。

📌 作品データ1998年7月から放送された全13話のオリジナルアニメです。制作はトライアングルスタッフで、監督は中村隆太郎さん、シリーズ構成・脚本は小中千昭さんです。

こんな人に：考察しながら見るダークなSFが好きな人！

3

彼氏彼女の事情

1998年秋 / GAINAX・J.C.STAFF / 恋愛・青春ドラマ
周囲には完璧な優等生として振る舞う高校生の男女が、お互いの素顔を知ったところから始まる恋愛ドラマです。庵野秀明さんが監督を務めたことでも知られています。

📌 作品データ1998年10月から1999年3月までテレビ東京系で放送された全26話の作品です。原作は津田雅美さんの漫画（白泉社「LaLa」）で、制作はGAINAXとJ.C.STAFFです。監督は庵野秀明さんです。

こんな人に：青春の恋と本音の話が好きな人！

4

千年女優

2002年公開 / マッドハウス / サイコサスペンス（劇場アニメ）
引退した伝説の女優の半生を、インタビューの形で振り返る劇場アニメです。回想の中で、女優が出演した映画の世界と現実が溶け合っていきます。第5回文化庁メディア芸術祭のアニメーション部門で大賞を受賞しました。

📌 作品データ2002年9月に公開された、上映時間87分の劇場アニメです。監督は今敏さん、脚本は村井さだゆきさんと今敏さん、制作はマッドハウスです。

こんな人に：映像表現にひたれるアニメ映画が見たい人！

5

灰羽連盟

2002年秋 / RADIX / ファンタジー・情緒
灰色の翼と頭の上の光の輪を持つ「灰羽」と呼ばれる少女たちが、壁に囲まれた街で共同生活を送る物語です。静かな日常の中に、自分の過去と向き合う重いテーマが流れています。

📌 作品データ2002年10月からフジテレビ系列の深夜枠で放送された全13話の作品です。安倍吉俊さんの同人誌『オールドホームの灰羽達』をもとにしています。制作はRADIXで、監督はところともかずさん、シリーズ構成・脚本は安倍吉俊さんです。

こんな人に：静かで切ないファンタジーが好きな人！

明日のナージャ

2003年冬 / 東映アニメーション / 少女・ファンタジー冒険
20世紀初頭のヨーロッパを舞台に、少女ナージャが生き別れた母を探して旅をする物語です。全50話をかけて、旅先での出会いと成長を描きます。

📌 作品データ2003年2月から2004年1月まで、テレビ朝日系列で毎週日曜の朝に放送された全50話の作品です。原作は東堂いづみさん、制作は東映アニメーションで、シリーズ構成は金春智子さんです。

こんな人に：長い旅の少女ドラマが好きな人！

7

プラネテス

2003年秋〜 / サンライズ / SF・宇宙
宇宙のゴミ（デブリ）を回収する仕事をしている人たちを主人公にした、近未来のSFです。宇宙へ出る夢と、仕事としての宇宙の現実の両方を描いています。宇宙空間のシーンで効果音をほとんど使わない演出も特徴です。

📌 作品データ2003年10月からNHK BS2で放送された全26話の作品です。原作は幸村誠さんの漫画（「モーニング」）で、制作はサンライズです。監督は谷口悟朗さん、シリーズ構成・脚本は大河内一楼さんです。

こんな人に：宇宙を舞台にした大人のドラマが見たい人！

8

妄想代理人

2004年冬 / マッドハウス / サイコサスペンス・ミステリー
金属バットを持った謎の少年による連続襲撃事件を、被害者や刑事たちの視点で描くサイコサスペンスです。今敏さんが唯一手がけたTVアニメとして知られています。

📌 作品データ2004年2月から5月までWOWOWで放送された全13話の作品です。原作・監督は今敏さん、制作はマッドハウスで、シリーズ構成は水上清資さんです。

こんな人に：ひねりのあるサスペンスが好きな人！

蟲師

2005年秋 / アートランド / ファンタジー・オムニバス
「蟲」と呼ばれる生き物と人間の間に起きる不思議な出来事を、旅をする蟲師・ギンコが解決していく一話完結の物語です。原作漫画に忠実に作られていて、落ち着いた空気の中で見られます。

📌 作品データ2005年10月から放送された全26話の作品です。原作は漆原友紀さんの漫画（講談社「月刊アフタヌーン」）で、制作はアートランド、監督は長濱博史さんです。

こんな人に：一話完結の静かなファンタジーが好きな人！

CLAYMORE

2007年春 / マッドハウス / ダークファンタジー・アクション
人間を襲う妖魔と、半人半妖の女戦士「クレイモア」が戦うダークファンタジーです。重い雰囲気のバトルと、戦士たちの運命が物語の中心になっています。

📌 作品データ2007年4月から日本テレビ系で放送された全26話の作品です。原作は八木教広さんの漫画（集英社「月刊少年ジャンプ」「ジャンプスクエア」）で、制作はマッドハウスです。監督は田中洋之さん、シリーズ構成は小林靖子さんです。

こんな人に：重めのダークファンタジーが好きな人！

電脳コイル

2007年春 / マッドハウス / SFジュブナイル・ミステリー
子どもたちが「電脳メガネ」をかけ、現実の町に重なったネットの世界を探検する近未来のSFです。都市伝説のような不思議な出来事を追ううちに、町の秘密に近づいていきます。日本SF大賞を受賞しました。

📌 作品データ2007年5月からNHK教育テレビで放送された全26話のオリジナルアニメです。原作・脚本・監督は磯光雄さんで、制作はマッドハウスです。

こんな人に：子どもが主役の本格SFが見たい人！

バッカーノ!

2007年夏 / ブレインズ・ベース / 群像劇・クライム
1930年代のアメリカを舞台に、不死の酒をめぐって、ギャングや錬金術師など多くの人物の物語が交差する群像劇です。時間軸を前後させる構成が特徴です。

📌 作品データ2007年7月からWOWOWで放送された全13話と番外編3話の作品です。原作は成田良悟さんのライトノベル（電撃文庫）で、制作はブレインズ・ベースです。監督は大森貴弘さん、シリーズ構成・脚本は高木登さんです。

こんな人に：群像劇やクライムものが好きな人！

喰霊-零-

2008年秋 / asread.・AICスピリッツ / ダークファンタジー・アクション
退魔を担う少女たちを描く、ダークなアクションです。原作漫画『喰霊』をもとにしたアニメで、「ノンストップ放課後退魔アクション」を掲げています。

📌 作品データ2008年10月から放送された全12話の作品です。原作は瀬川はじめさんの漫画（角川書店「月刊少年エース」）で、制作はasread.とAICスピリッツです。監督はあおきえいさん、シリーズ構成・脚本は高山カツヒコさんです。

こんな人に：シリアスな退魔アクションが好きな人！

14

東のエデン

2009年春 / Production I.G / サスペンス・SF
記憶を失った青年が、不思議な携帯電話を手に、日本を救うゲームに巻き込まれていくサスペンスです。ノイタミナ枠で放送され、神山健治さんにとって初のオリジナルストーリーのアニメでした。

📌 作品データ2009年4月からフジテレビの「ノイタミナ」枠で放送された全11話のオリジナルアニメです。制作はProduction I.Gで、原作・監督・シリーズ構成は神山健治さんです。放送後に、総集編と劇場版2作品も作られました。

こんな人に：先の読めないサスペンスが見たい人！

こばと。

2009年秋 / マッドハウス / ファンタジー・ヒューマンドラマ
心に傷を抱えた人たちを、小さな少女・こばとが癒やそうとするファンタジーです。CLAMPさんの原作を、マッドハウスがアニメにしました。

📌 作品データ2009年10月から2010年3月までNHK BS2ほかで放送された全24話の作品です。原作はCLAMPさんの漫画で、制作はマッドハウスです。監督は増原光幸さんです。
